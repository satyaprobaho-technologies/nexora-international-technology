# NEXORA INTERNATIONAL TECHNOLOGY

**Your Digital World Starts Here.**

Independent website development, domain and hosting services platform.

## Project status
This repository contains the initial Next.js 15 starter. Domain registration, hosting provisioning, payment processing and customer authentication are demo/planned integrations until approved provider credentials and accounts are configured.

## Requirements
- Node.js >=20.9
- npm

## Run locally
```bash
npm install
npm run dev
```

## Validate
```bash
npm run typecheck
npm run build
```

## Deploy
Connect this repository to a supported Next.js host (Cloudflare Pages requires an appropriate adapter; do not deploy as plain static export when server features are enabled). Configure environment variables from `.env.example`.

No credentials or production payment details belong in source control.
