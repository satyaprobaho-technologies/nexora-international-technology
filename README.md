# NEXORA INTERNATIONAL TECHNOLOGY

**Your Digital World Starts Here.**

A responsive Next.js website for presenting NEXORA's website development, domain/hosting guidance and digital support services.

## Current live scope
- Responsive marketing website with service descriptions and 50 distinct website concept cards.
- Email enquiry links using the contact address supplied by the owner.
- Metadata, Open Graph basics, sitemap and robots directives.
- GitHub Actions workflow for typecheck and production build validation.
- Deployed to Vercel: https://nexora-international-technology.vercel.app/

## Important service limitations
The website is an enquiry and service-information site. It does **not** currently sell or register domains, provision hosting, accept payments, create customer accounts, or send contact-form submissions to a backend. Those features require approved registrar/hosting/payment providers, credentials, server-side implementation, privacy/terms policies and testing. Do not represent these as active until integrated and verified.

## Requirements
- Node.js >=20.9
- npm

## Run
```bash
npm install
npm run dev
```

## Validate
```bash
npm run typecheck
npm run build
```

Never commit API keys, passwords, payment credentials or private tokens.
